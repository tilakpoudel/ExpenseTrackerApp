## 💡 Code Quality Guidelines
- **Language**: Pure Java (No Kotlin).
- **Layouts**: Native XML Layouts (No Jetpack Compose).
- **Comments**: Every class, method, and key XML attribute is thoroughly commented for bachelor-level BCA students.
- **Material Design**: Uses Material Components (`MaterialCardView`, `MaterialButton`, `BottomNavigationView`).
